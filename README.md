# 💻 Bilişim Teknolojileri Öğrenme Platformu

5. ve 6. sınıf bilişim teknolojileri dersi için profesyonel ve eğlenceli öğrenme platformu.

## 🎯 Özellikler

### 🎮 Oyun Sistemleri
- **Bilgi Yarışması**: Quiz soruları ile öğrenme
- **Eşleştirme Oyunu**: Emoji-term eşleştirme
- **Sıralama Oyunu**: Adım sıralama ile mantık geliştirme

### 🌟 Profesyonel Özellikler
- **3D Emoji Sistemi**: Three.js ile gerçek 3D render
- **Ses Efektleri**: Howler.js ile profesyonel sesler
- **Animasyonlar**: GSAP ile akıcı geçişler
- **Responsive Tasarım**: Mobil uyumlu arayüz

### 📚 Öğrenme Alanları (MEB Müfredatına Uygun)

#### 5. Sınıf
- 💻 Bilişim Teknolojileri
- 🖥️ Bilgisayar Donanımı
- 🔒 Güvenlik ve Etik
- 🤖 Yapay Zekâ

#### 6. Sınıf
- 🚀 Yenilikçi Teknolojiler
- 📡 İletişim Teknolojileri
- 🌐 Bilgisayar Ağları
- 💻 Programlama Temelleri

## 🚀 Kullanım

### Gereksinimler
- Modern web tarayıcısı (Chrome, Firefox, Safari, Edge)
- İnternet bağlantısı (CDN kütüphaneleri için)

### Kurulum
1. Projeyi indirin veya klonlayın
2. `index.html` dosyasını tarayıcınızda açın
3. İstediğiniz sınıfı seçin
4. Öğrenmeye başlayın!

### Yapı
```
BilisimTeknolojileri/
├── index.html          # Ana sayfa (sınıf seçimi)
├── 5-sinif/            # 5. sınıf içerikleri
│   ├── index.html
│   ├── script.js
│   └── style.css
└── 6-sinif/            # 6. sınıf içerikleri
    ├── index.html
    ├── script.js
    └── style.css
```

## 🎨 Teknolojiler

- **Three.js**: 3D grafikler ve animasyonlar
- **GSAP**: Profesyonel animasyon kütüphanesi
- **Howler.js**: Ses yönetim sistemi
- **HTML5/CSS3**: Modern web teknolojileri
- **JavaScript**: Etkileşimli oyun mantığı

## 📖 Kullanım Kılavuzu

### Oyun Nasıl Oynanır?
1. Ana sayfadan sınıfınızı seçin
2. İstediğiniz oyun türünü seçin (Quiz, Eşleştirme, Sıralama)
3. Soruları cevaplayın ve puan kazanın
4. Öğrenme alanlarından konuları detaylı öğrenin

### Puan Sistemi
- **Quiz**: Her doğru cevap 10 puan
- **Eşleştirme**: Her doğru eşleşme 10 puan
- **Sıralama**: Her doğru sıralama 15 puan
